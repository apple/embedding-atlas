# Examples

This folder contains examples showing how to use components and algorithms from the npm package.

## Running the examples

1. Run `npm run build` at the repository root. It builds `embedding-atlas` and the `umap-wasm` package. This needs the Rust toolchain and the wasm-bindgen CLI at the version in the root `Cargo.toml`. See [packages/docs/develop.md](../docs/develop.md) for the setup.
2. Launch the dev server in this folder:

```bash
npm run dev
```
